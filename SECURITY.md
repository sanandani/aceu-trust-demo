# Security policy

Report suspected vulnerabilities privately to the repository maintainers through GitHub's private vulnerability reporting. Do not include tenant exports, access tokens, client secrets, or other credentials in public issues. Revoke any credential that may have been exposed.

This project is read-only and does not claim that a high score establishes a secure configuration. Verify Graph permissions and results independently.
