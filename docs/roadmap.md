# Roadmap

Good first issues for this project:

1. Add Conditional Access for workload identities coverage checks.
2. Add sign-in log checks and define a safe lookback window.
3. Identify named privileged app roles and distinguish their risk.
4. Inventory and score managed identities comprehensively.
5. Add coverage for Microsoft Entra agent identities.
6. Add a self-contained HTML report.
7. Provide `azd` and Bicep deployment examples for least-privilege setup.
8. Support YAML-configured thresholds and weights.
9. Add JUnit XML output for CI systems.
10. Add a Docker Compose example for local offline use.
